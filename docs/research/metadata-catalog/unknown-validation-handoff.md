## Evidence limits and next handoff

- The prior census measured 48 direct `~/dev` Salesforce roots with 63,238 components and 559,786 unresolved edges summed across roots. Overlapping repositories mean these are not unique totals; this review did not reproduce the census from a persisted per-root artifact. An unresolved edge means the target is not a scanned local node, not that it is absent from a target org.
- Current `getDeploymentPriority` throws for unknown _local node_ types; an absent referenced target may instead leave its consumer unplaced. Do not repeat the older catalog claim that every unknown executes at priority 99 (`src/constants/deployment-order.ts`, `src/waves/wave-builder.ts`).
- QA confirmed the above by static code and fixture inspection, not executed tests. The matching-rule gap fixture's singular `<MatchingRule />` root only exercises suffix/name detection, not a valid retrieved container (`test/unit/analysis/metadata-gap-analysis-service.test.ts`). Reports C2/C3/C7 also contain stale API 61.0 project-version statements; the current project is 67.0.
- Before marking AC-001/002 verified, persist per-key sanitized sample IDs and reproducible check output, run deterministic positive and negative fixtures, and independently challenge the results. Before any execution claim, supply relevant target-org/provider evidence. AC-003 is an advisory backlog and cross-cluster owner review only; AC-004 held for this research pass.
