# Product UX Validation Playbook

## Product / BA Validation

- Compare UX artifacts against the story, user goal, acceptance criteria, assumptions, and edge cases.
- Confirm the UX design does not silently expand scope or remove required user outcomes.
- Re-check functional sizing after UX discovery; split into smaller stories if the validated flow now includes separate journeys or outcomes.
- Resolve copy, workflow, information architecture, and state-behavior questions before architecture starts.
- Record approve, changes, or block with concrete findings and the artifacts reviewed.
