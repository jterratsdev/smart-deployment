# UX Design Playbook

## UX Design

- Translate acceptance criteria into a concrete user flow before architecture starts.
- Define layout intent, navigation, component states, loading, empty, error, success, and recovery behavior.
- Specify mobile-first behavior, accessibility expectations, copy, labels, and tooltip needs.
- Identify user-facing data/API needs, validation rules, and edge cases that architecture must account for.
- Attach wireframe, annotated screenshot, flow diagram, or compact UX spec when UI behavior is affected.
- Record assumptions, open questions, and scope changes that require Product/BA validation before architecture.
