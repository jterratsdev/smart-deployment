# Documentation Review Playbook

## Doc Review

- Identify the authoritative docs, README, changelog, public site, runbook, and prompt registry surfaces affected by the change.
- Validate command examples against the command manifest, help output, or repo-local CLI.
- Keep user-facing copy concise, current, and aligned with the implemented behavior.
- Record docs updated, docs intentionally deferred, and any support/customer-facing notes.
