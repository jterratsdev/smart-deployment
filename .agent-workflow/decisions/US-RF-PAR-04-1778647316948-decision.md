# Decision US-RF-PAR-04: Split layout parser into section, action, reference, and assembly collaborators

- Status: accepted
- Owner: architect

## Context

layout-parser.ts combined XML root parsing, section normalization, action extraction, reference extraction, optional dependency assembly, and result construction in one 474-line file.

## Decision

Keep parseLayout as the I/O and orchestration boundary, extract layout-section-analysis, layout-action-analysis, layout-reference-analysis, and layout-result-assembly modules.

## Consequences

Layout parser is reduced to 129 lines; metadata extraction concerns can evolve independently while LayoutParseResult remains stable.
