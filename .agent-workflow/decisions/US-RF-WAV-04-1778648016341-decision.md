# Decision US-RF-WAV-04: Extract cache storage, TTL, serialization, key, and lock collaborators

- Status: accepted
- Owner: architect

## Context

cache-manager.ts contained singleton orchestration plus persistence, serialization, expiry policy, key derivation, cleanup, and file lock lifecycle in one 664-line file.

## Decision

Keep CacheManager as the public cache API and singleton boundary; extract storage, serializer, expiry policy, key derivation, logger, and lock lifecycle modules.

## Consequences

CacheManager is reduced to 378 lines; storage and lock side effects are isolated; cache API and persisted file behavior remain stable.
