# Decision DQ-005: Block unsafe dynamic SOQL consumers before real deployment

- Status: accepted
- Owner: architect

## Context

DQ-004 can report target-org missing fields. The start execution path is the narrowest place that can prevent real deployments without changing dry-run or validate-only behavior.

## Decision

Run DynamicQueryTargetValidator after target-org is required and before DeploymentRunner executes, raising an actionable diagnostic when missing fields remain.

## Consequences

Dry-run and validate-only stay non-deploying; real deployments fail fast before manifests/deploy calls when dynamic SOQL prerequisites are absent.
