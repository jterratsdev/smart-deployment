# Decision DQ-001: Expose Apex dynamic SOQL references as parser output

- Status: accepted
- Owner: architect

## Context

Apex parser emitted static class dependencies only. Dynamic SOQL field references need a structured contract before dependency graph ordering can consume them.

## Decision

Add DynamicQueryReference to ApexParseResult and keep dynamic SOQL extraction in a focused apex-dynamic-query-analysis parser helper.

## Consequences

Graph integration can consume field references without adding SOQL parsing logic to CLI commands or dependency orchestration.
