# Decision US-RF-WAV-03: Split wave validation into transport, prompt, parser, synthesis, and report modules

- Status: accepted
- Owner: architect

## Context

wave-validation-service.ts mixed provider calls, prompt construction, JSON parsing, fallback risk generation, result synthesis, and report rendering in one 608-line service.

## Decision

Keep WaveValidationService as the public orchestration boundary and extract prompt, transport, response parser, result synthesis, and report formatting collaborators.

## Consequences

validateWaves() remains stable; AI response parsing and risk synthesis can be tested or evolved without provider transport concerns; service is reduced to 180 lines.
