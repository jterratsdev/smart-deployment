# Decision DQ-EPIC-001: Treat dynamic SOQL field references as deployment prerequisites

- Status: accepted
- Owner: architect

## Context

Apex and Custom Metadata can hide field references inside runtime query strings. Salesforce deployments can fail when Apex or CMDT consumers are installed before those fields exist in the target environment.

## Decision

Introduce structured dynamic query references, promote local fields into dependency graph edges, validate unresolved fields against target org when available, and block only high-confidence missing prerequisites before sf project deploy start.

## Consequences

Wave analysis becomes safer for runtime SOQL dependencies while preserving conservative behavior for ambiguous dynamic strings. The feature must keep extraction, graph reasoning, org I/O, and presentation in separate modules.
