# Decision DQ-002: Use a shared dynamic query reference contract for Apex and CMDT

- Status: accepted
- Owner: architect

## Context

Apex and Custom Metadata both need to expose SOQL field references for later graph ordering without duplicating SOQL field parsing.

## Decision

Move DynamicQueryReference primitives into a focused parser helper and have CMDT records emit dynamicQueryReferences from SOQL values and object-plus-field-list configuration values.

## Consequences

DQ-003 can consume one reference shape from Apex and CMDT while parser modules remain responsible only for extraction.
