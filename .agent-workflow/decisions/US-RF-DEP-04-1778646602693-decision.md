# Decision US-RF-DEP-04: Separate cycle discovery from remediation policy

- Status: accepted
- Owner: architect

## Context

Circular dependency detection mixed graph traversal, raw cycle materialization, deduplication, severity creation, and remediation suggestion priority in one detector module.

## Decision

Keep the detector as orchestration and result assembly, extract raw cycle traversal into CycleDiscovery, and extract break suggestion scoring into a focused suggestion module.

## Consequences

Cycle discovery can be tested without remediation policy; suggestion priority can evolve independently; the public DetectedCycle contract stays unchanged.
