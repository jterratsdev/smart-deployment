# Decision DQ-003: Promote dynamic query references through scanner dependencyDetails

- Status: accepted
- Owner: architect

## Context

The graph already consumes MetadataComponent dependencyDetails. Parser output should enter graph ordering through scanner adapters rather than graph-specific logic in parsers.

## Decision

Convert Apex and CMDT dynamic query references to hard CustomField:Object.Field dependencyDetails in scanner adapters, preserving existing declared dependencies in the same structured list.

## Consequences

Wave ordering can place known CustomField nodes before Apex/CMDT consumers. Missing local field nodes remain detectable by later validation work.
