# Open Orchestra Integration

This directory is generated by `setup-agents` only when Open Orchestra integration is explicitly requested.

## Boundary

- `setup-agents` installs Salesforce-focused agent rules, profiles, skills, and local state scaffolding.
- Open Orchestra owns runtime orchestration: task graphs, locks, reviews, evidence, gates, budgets, and provenance.
- This integration does not make Open Orchestra a required dependency of `setup-agents`.

## Next Step

Run this only when you want Open Orchestra to create runtime workflow state:

```sh
orchestra init
```

If `orchestra` is not available, install or link Open Orchestra first.

## Files

- `profiles.json` maps selected setup-agents profiles to Open Orchestra-compatible role hints, activation criteria, expected evidence, and gates.
