## Phase Recovery Procedures

### pm

Review task goals and acceptance criteria
Check `.setup-agents/state/tasks.jsonl` for context
Validate story decomposition is complete

### ba

Review requirements in task description
Check story mapping artifacts in `.setup-agents/skills/story-mapping/`
Verify acceptance criteria coverage

### architect

Review decisions in `.setup-agents/state/decisions.jsonl`
Check architecture docs in `docs/`
Validate technical approach aligns with constraints

### developer

Read source code for context: `git log --oneline -10`
Check test coverage: run local tests
Follow coding standards from profile rules
Record evidence: commands run, files modified

### qa

Run test suite locally
Verify acceptance criteria from task
Record test results as evidence
Check for regressions

### document-review

Locate the authored source and intended final output
Run the document quality review playbook independently from the author
Verify grounding, consistency, audience/tone, scope, decisions, and sensitive content
Record an approved review for the exact source digest (`sf setup-agents docs digest`) before rendering

### release

Validate deployment: `sf project deploy validate`
Check release checklist
Verify all evidence and reviews recorded

## Local LLM Configuration (Optional)

If you have a local LLM runtime available, configure it in `.setup-agents/config.json`:

```json
{
  "localLlm": {
    "endpoint": "http://localhost:11434/v1",
    "model": "llama3.2",
    "provider": "ollama"
  }
}
```

Supported providers: ollama, llama.cpp, vLLM, LM Studio, or any OpenAI-compatible endpoint.
