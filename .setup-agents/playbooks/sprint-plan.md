# Sprint Plan

## Goal

Review the backlog and define the sprint goal, scope, and capacity.

## Steps

1. Read open backlog items from `.setup-agents/state/` or the linked Jira board.
2. Confirm scope with the team: which stories fit in this sprint?
3. Write the sprint goal in one sentence.
4. List selected stories with estimated effort (S/M/L).
5. Record risks or blockers in a `risk-register.md` note.
6. Record evidence: `sf setup-agents evidence add --task <id> --type file --summary "Sprint plan written"`
