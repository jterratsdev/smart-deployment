This project uses the `sf setup-agents` Salesforce Code Agent plugin for its agent rules,
skills, and workflow. This file intentionally does not contain them yet.

**If you don't have the plugin installed:**

1. Install it: `sf plugins install @jterrats/setup-agents` (or your project's
   documented install command).
2. Generate your local agent configuration — run this **in your own terminal, not by asking
   an AI agent to run it for you**: `sf setup-agents local`
3. Restart your editor/agent session so it picks up the generated files.

Until step 2 runs, Claude and other agents in this clone have no project-specific rules,
profiles, or workflow — only this file's prose.
